# Studio Click

Landing page estática da Studio Click, pronta para hospedagem via GitHub Pages.

## Estrutura

- `index.html` — conteúdo e estrutura
- `css/style.css` — estilos e responsividade
- `js/script.js` — navegação, animações e funil de WhatsApp
- `assets/projects/` — logos dos trabalhos (máximo recomendado: 3)
- `assets/gallery/` — imagens da galeria (máximo recomendado: 3)

## Personalização

1. Substitua os arquivos SVG temporários em `assets/projects/` pelos logos dos clientes.
2. Atualize os links dos cards de projeto no `index.html`.
3. Substitua os arquivos em `assets/gallery/` pelas imagens reais.
4. Ajuste nome, textos ou contatos diretamente no HTML.

## Publicação

No GitHub, habilite o **GitHub Pages** em *Settings > Pages*, selecionando a branch principal e a pasta raiz (`/`).
